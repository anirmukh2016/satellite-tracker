How It Works ▲

SGP4 (Simplified General Perturbations 4) predicts satellite positions from TLEs — compact orbital parameter sets updated twice daily by NORAD.


ECI frame (toggle above): fixed to distant stars. SGP4 outputs position here. Axes don't rotate.


ECEF frame: rotates with Earth. GMST (θ) is the rotation angle between ECI-X and ECEF-X, increasing by 360° every 86,164 seconds.


Both frames use the same colour per axis (X Y Z): solid = ECI, dashed = ECEF. The white arrow is the ISS position vector — the same vector in both frames, just with different components.
